# 评估方案：主指标、对照实验与证伪条件

这份文档回答一个问题：凭什么相信这套自进化系统比朴素做法更好？答案是一组可以被执行、也可以被判负的对照实验。读完后你应当能自己搭出这组实验，并对结果做出不带立场的解释。

## 主指标

系统的目标定义为：

> 每单位真实实验成本，发现的独立、可复现、典型且可定位的短板根因数量。

拆开说，每个词都有操作含义：

- **每单位真实实验成本**：分母是真实配对执行次数或机器小时。生成、预判、去重的计算成本不进分母——它们相对物理执行近乎免费，但也因此不构成炫耀的资本。
- **独立**：按根因去重。同一根因的一百个参数变体算一个发现。
- **可复现**：按相同步骤重复得到同方向差距，且适用条件（负载、配置、缓存状态、数据规模）写清楚了。
- **典型**：属于有现实意义的负载，不是为了制造巨大差距而构造的畸形程序。
- **可定位**：差距能归因到目标系统的具体行为特征，而不是“两边不一样”。

这个指标刻意排除了两类常见的虚报。“没有退化”不能算成功——永远不更新就能实现它。“预测准确率高”也不能算——系统可能只在自己熟悉的一小片空间上准确，那片空间之外它一无所知。

## 辅助指标

辅助指标用来解释主指标的变化，不能替代主指标：

| 指标 | 回答的问题 |
| --- | --- |
| 新根因发现速度 | 系统是不是在持续发现，还是 early saturation 后就在重复 |
| 负载族覆盖 | 发现是分布广泛还是集中在熟悉区域 |
| 预判器假阴性率 | 预判器漏掉了多少，由随机审计样本估计 |
| 预判器校准度 | 判定值与实际频率的偏差，方差预测与实测噪声的对照 |
| 去重器误合并率 | 被判冗余的样本里，实际物理行为不同的比例 |
| 去重器误拆分率 | 被保留为不同的样本里，反复产生相同轨迹与根因的比例 |
| 审核器误放率 | 接受的更新里，窗口评估为负收益的比例 |
| 审核器误杀率 | 拒绝的更新里，回放或试行证明有收益的比例 |
| 旧能力退化程度 | 旧负载族与历史探针上的表现变化 |
| 改坏后的恢复时间 | 一次误放从发生到定位、回滚、避免复发花了多久 |
| 同类错误复发率 | 同一种误判模式是否反复出现 |
| 版本迁移适用性 | 目标系统版本变化后，积累的知识还有多少成立 |

## 对照实验

在相同的真实执行预算下，逐步比较四组：

- **A：固定生成器，全部真实执行。** 传统方案，一切收益的基线。
- **B：A ＋ 预判器主动调度。** 保留不确定样本与随机审计预算，不做硬过滤。
- **C：B ＋ 生成器自进化。** 生成器按物理结果调整生成策略。
- **D：C ＋ 审核器自进化。** 审核器从误放、误杀与自身退化中学习信用分配。

每一组跑多个轮次、多个初始条件，并在训练中没见过的负载族上做一次终测。单次实验、单一初始条件下的领先不足为凭。

## 证伪条件

每一层组件都有一个明确的判负条件：

- **B 不超过 A**：预判器没有调度价值。它最多保留为分析工具，不该影响执行决策。
- **C 不超过 B**：生成器自进化没有带来额外发现收益。它可能在复制已知有效模式，而不是探索。
- **D 不超过 C**：审核器的自我感知与信用分配没有实际价值。这是最可能判负的一层，也是研究价值最高的一层——慢循环的信用分配数据稀疏，本来就不能假设会成功。
- **D 更稳定但新根因更少**：审核器只是学会了保守，而不是学会了审核。这种结果看起来“安全”，实际上是系统停止进化的信号。
- **随机审计显示严重漏报**：探索预算或置信度校准失效，系统已经封闭，此前的指标一律不可信。

只有 D 在多轮实验、不同初始条件、未见负载族上稳定超过前面各组，且审计没有显示严重漏报，完整的自进化闭环才值得保留。

## 实验之外的纪律

有几条纪律不属于某一次实验，但决定所有实验的可信度：

1. **真值记录不可改写。** 判定档案一旦写入，真值到达只追加不覆盖。任何组件的更新都不能事后修改原始测量结果或成功定义。
2. **探索概率如实记录。** 每次决策记下探索所占的概率，否则误杀率无从估计，探索样本会被误当成组件原本的策略。
3. **审计预算不挪用。** 高置信否决的随机审计样本是真值的最后防线。置信度校准一旦失真，只剩它能暴露问题。
4. **一次窗口一个主要因子。** 必须同时改多个组件时，靠回放与消融补做归因，不把整体变化笼统记在某一次更新头上。
5. **版本绑定。** 所有数据绑定目标系统版本、对照系统版本、配置与硬件环境。某个旧短板被修复后，旧标签不应继续支配当前预测——“不遗忘”不是无条件的美德，重新验证才是。
